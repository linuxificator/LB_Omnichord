# External controller profiles

These profiles configure third-party controllers to emit standard MIDI
messages understood by LB Omnichord. They are optional device-side assets, not
runtime dependencies and not application-specific MIDI translation tables.

- [`novation_flkey_mini/`](novation_flkey_mini/README.md): General MIDI drum
  layout for the original Novation FLkey Mini's 16-pad Custom Mode.
