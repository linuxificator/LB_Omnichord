# Dependency assessment: NumPy

Date: 2026-09-01
Decision: adopt as an explicit test dependency (existing direct use)
Owner: test and quality requirements
Requirement and code replaced/prevented: removes reliance on AMY's transitive,
unconstrained NumPy install for `tests/instrument_balance.py`
Owning dependency group: `requirements-test.txt`

## Fit and scope

The balance renderer uses array concatenation, peak/RMS reduction, clipping,
sample counting and PCM conversion on arrays returned by AMY. NumPy is already
the native array type used by AMY and is the established complete solution;
rewriting those vector operations is unjustified. No NumPy object enters
frontend runtime/domain state.

## Maintenance, adoption, license and security

NumPy is an actively maintained, broadly adopted scientific-Python foundation.
The selected 2.5.2 patch release was published on 2026-08-09 and supports
Python 3.12 through 3.15 according to the
[official release notes](https://numpy.org/devdocs/release/2.5.2-notes.html).
The package publishes platform wheels and provenance on its
[official PyPI project](https://pypi.org/project/numpy/). Its licenses are
compatible with test use and are reported in the distribution metadata.

## Platform, runtime and exit cost

The importing LB code runs only in offline/native test rendering; it is not in
the UI, MIDI, command scheduling or audio callback path. The selected version
matches the current project environment and supports the workflow's Python
3.12. AMY already returns NumPy-compatible arrays, so the boundary is small.
If AMY changes its render array contract, this test tool and pin can be updated
or removed without migrating user data or application APIs.

## Accepted input and follow-up

Accepted: `numpy==2.5.2` in the test group. T24 must record the separately
resolved NumPy version pulled as a transitive dependency when packaging the
pinned AMY component; that does not make NumPy a portable frontend runtime
dependency.
