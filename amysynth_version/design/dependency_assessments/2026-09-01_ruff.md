# Dependency assessment: Ruff

Date: 2026-09-01
Decision: adopt as a test/quality command
Owner: test and quality requirements
Requirement: fast correctness lint for every Python change without formatting
or runtime coupling
Owning dependency group: `requirements-test.txt`

## Decision evidence

Ruff combines mature Flake8-family correctness checks in one fast standalone
tool, has first-party `pyproject.toml` support and does not enter application
code. It is actively developed and backed by Astral, with broad documented use
including Airflow, FastAPI, Pandas and SciPy. The selected 0.16.5 release and
usage are recorded on the [official PyPI page](https://pypi.org/project/ruff/)
and configuration follows the
[official documentation](https://docs.astral.sh/ruff/configuration/).

Ruff is MIT licensed and publishes standalone wheels for the Linux quality
runner. It runs only during source analysis; release platforms do not import or
package it. The initial gate enables only correctness-critical rules and has
one narrow legacy `F821` exception in `app_core.py`; it does not format or
rewrite existing source. Removal is low-cost because no Ruff type/API appears
in project data or code.

Accepted input: `ruff==0.16.5`. Review the pin when expanding the rule set or
when the quality runner's Python/platform changes.
