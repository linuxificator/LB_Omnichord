# TB-303-style instrument and articulation

Status: implementation contract
Owner: instrument programs and bass sequence planning
Applies to: active `amysynth_version` implementation
Last verified: 2026-09-09

## Scope

`TB-303` is one instrument choice in the shared chord, strum, bass and MIDI
catalogue. Its subtractive voice and editable controls work in every role.
Only the Omnichord bass sequencer interprets the catalogue's `accent` and
`slide_to_next` annotations; chord, strum, MIDI and ordinary bass instruments
retain their existing note behavior.

The implementation is a 303-style AMY voice, not a claim of circuit-level
Roland TB-303 emulation.

## Timing ownership

The frontend may validate musical data and compile a finite reusable-sequence
definition when configuration changes. AMY owns every onset, release, pitch
transition, envelope and repeat after that definition is sent. The frontend
must not poll AMY's clock, mirror active notes, stream glide steps, or use a
timer to produce bass articulation.

The resulting wire plan must be identical for local sockets, the Windows
named pipe, Android IPC and ESP32-P4 serial transport.

## Conservative accent decision

The current AMY envelope generators retrigger with a positive-velocity note
event. Such an event at the destination of an already sounding slide would
also retrigger the ordinary amplitude envelope and participate in instrument
note bookkeeping. That is not the requested legato articulation.

Therefore this implementation deliberately ignores `accent=true` when that
event is the destination of a `slide_to_next` edge. Accents on detached
attacks remain supported, and slide pitch/portamento behavior remains
supported. No frontend timing workaround and no new AMY engine operation is
introduced. A future independent envelope-trigger facility would require a
separately designed, generic AMY API and native tests before this limitation
can be removed.

## Compatibility

Ordinary bass instruments ignore both articulation flags and preserve every
authored duration and velocity. Existing presets without `TB-303` retain their
instrument and sequence behavior. Selecting `TB-303` for a non-bass role uses
the same voice controls but never applies bass-riff articulation policy.
