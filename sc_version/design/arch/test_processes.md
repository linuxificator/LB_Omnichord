# Test process boundaries

Status: authoritative integration-test contract
Owner: test architecture
Applies to: `sc_version/qt_frontend/tests`
Last verified: 2026-09-15

Production modules contain no synthetic input endpoints or test-only receivers.
External MIDI/OSC stimulus is generated by a separate process. A process claim
uses the normal adapter/protocol and observes a separately launched frontend
and fake or real SC coordinator. Unit tests may call one narrow object directly
but cannot substitute for process evidence.

Generic protocol tests are shared across supported platforms. Native capability
setup is isolated under `tests/platform/<platform>/`; it must not fork the
musical contract. Test helpers use semantic client methods and never expose raw
engine commands or firmware diagnostics.
